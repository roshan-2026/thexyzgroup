Place your raster images here, for example:

- og-image.png  (1200x630px) — used for Open Graph / Twitter card previews,
  referenced in index.html as assets/images/og-image.png
- Any project thumbnails you want to use instead of the SVG icons in
  assets/icons/

The homepage currently uses lightweight SVG icons (assets/icons/) for crisp,
fast-loading visuals with no raster images required. This folder is provided
for when you're ready to add real screenshots, thumbnails, or the OG image.
